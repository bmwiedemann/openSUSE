# Packaging netbird-ui (wails application)

In addition to the source code in the tarball, this package also needs the
assets for the web UI. These can be generated by the `Makefile` that is present
in this package.  To do that, you need to have `make` and `podman` installed
locally.  For the OBS workflow you also need `obs-service-go_modules` as well as
`obs-service-tar_scm` and `obs-service-recompress`.

1. Change the version in the `_service` file
2. Run `make`
3. Create a changelog entry
4. Commit the changes as usual
5. If desired, remove the container image used to build the web assets:

   ```
   podman image rm registry.opensuse.org/opensuse/tumbleweed:latest
   ```

Note that leap would be used here, but it doesn't have the necessary
webkit6/GTK4 libraries, thus necessitating using a tumbleweed snapshot.
I'm not entirely sure how long tumbleweed container images are kept in 
the registry, and pulling :latest is liable to cause issues (it did for me
the first time I tried to build web assets with it). This strategy may be
adjusted slightly in the future. This workaround was shamelessly modified
from ojkastl's woodpecker/other builds (thanks for the inspiration)!
