# The openSUSE Tumbleweed RabbitMQ message broker supporting AMQP, STOMP and MQTT container image
![Redistributable](https://img.shields.io/badge/Redistributable-Yes-green)

RabbitMQ message broker supporting AMQP, STOMP and MQTT container based on the openSUSE Tumbleweed Base Container Image.
